# AI Ticket Assistant

Учебный проект интеллектуальной системы обработки заявок сотрудников.

## Возможности

- Приём обращений сотрудников
- Определение отдела и приоритета заявки
- Сохранение истории обращений в JSON
- Автоматическая нумерация заявок
- Поддержка классификации через LLM (Ollama API)
- Резервная классификация по правилам Python

## Технологии

- Python
- JSON
- REST API
- Ollama (для подключения LLM)

## Запуск

```bash
python main.py
```

По умолчанию используется классификация по правилам.

Для использования нейросети необходимо установить Ollama,
загрузить модель qwen2.5:1.5b и установить USE_AI = True
в файле classifier.py.

## Статус

Рабочий прототип. Интеграция с LLM реализована в коде,
но пока не протестирована на запущенной модели.
